# Keguang Cheng

Source files for [my academic website](https://keguangcheng.github.io/), featuring research, publications, coursework, field experience, and personal interests.

## Editing and preview

- Page text: `_pages/`
- Shared content: `_data/`
- Website photos: `images/`
- Public CV and transcripts: `files/`
- Editing guide: [CONTENT_GUIDE.md](CONTENT_GUIDE.md)
- Local preview and publishing: [PREVIEW.md](PREVIEW.md)

GitHub Pages builds the website from the root of the `master` branch. Local source photos, working materials, backups, and generated previews are excluded from Git.
